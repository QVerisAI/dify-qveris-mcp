# Contributing

1. Create a focused branch from `main`.
2. Use Python 3.12 and install `.[test]`.
3. Run `python -m pytest` before opening a pull request.
4. Keep `requirements.txt` and `pyproject.toml` dependencies in sync.
5. Do not add credentials, captured user payloads, or unrestricted outbound domains.
6. Explain protocol, privacy, or billing behavior changes in the pull request.
