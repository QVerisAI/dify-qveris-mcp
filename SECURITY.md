# Security Policy

Please report vulnerabilities privately to `contact@qveris.ai`. Do not open a public issue for an unpatched vulnerability.

Include the affected version, reproduction steps, expected impact, and any suggested remediation. Never include live API keys, endpoint tokens, or personal data in a report.

The plugin supports the current `0.1.x` release line. Rotate both the endpoint bearer token and QVeris API key if either may have been exposed.
